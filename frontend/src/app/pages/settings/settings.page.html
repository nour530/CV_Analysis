AI privacy

Optional explanations

Opt-in only

Remote AI explanations require all of the following: the request flag include_llm, explicit consent through allow_remote_analysis, and the server setting ALLOW_REMOTE_LLM_ANALYSIS=true.

If any requirement is missing, the app keeps the local deterministic score and shows no AI explanation. No API keys are present in Angular.
